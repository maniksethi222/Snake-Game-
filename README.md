# 🐍 Snake Game

A classic Snake Game built with HTML, CSS, and JavaScript — smooth gameplay with score tracking!

---

## 🎮 How to Play

- Press **Arrow Keys** to move the snake
- Eat the 🍎 food to grow longer
- Don't hit the **walls** or your own **tail**
- Try to get the **highest score!**

---

## ✨ Features

- Smooth snake movement
- Score tracking
- Game over detection
- Increasing speed as snake grows
- Clean & minimal UI

---

## 🛠️ Tech Stack

| Technology | Use |
|-----------|-----|
| HTML5 Canvas | Game Rendering |
| CSS3 | Styling |
| JavaScript | Game Logic |

## 🚀 How to Run

1. Clone the repository
```bash
git clone https://github.com/maniksethi222/Snake-Game-.git
```

2. Open the folder
```bash
cd Snake-Game-
```

3. Open `index.html` in your browser — Game On! 🎮✅
